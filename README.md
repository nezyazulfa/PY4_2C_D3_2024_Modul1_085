# Proyek 4: Pengolahan Citra Digital (Vision Enhancer)

Aplikasi ini dikembangkan menggunakan Flutter murni (tanpa dependensi native C++ yang berat) menggunakan `package:image` untuk mendemonstrasikan berbagai operasi pengolahan citra dari ranah spasial hingga frekuensi.

## Cara Instalasi dan Menjalankan Proyek

1. Ekstrak file .zip ini ke direktori yang **TIDAK memiliki spasi** pada namanya (contoh: `D:/ProyekPolban/`).
2. Buka proyek menggunakan Visual Studio Code atau Android Studio.
3. Buka Terminal dan jalankan perintah berikut untuk mengunduh library yang dibutuhkan:
   ```bash
   flutter pub get
4. Pastikan perangkat Android (fisik atau emulator) sudah terhubung.
5. Jalankan aplikasi dengan perintah:
    flutter run
Catatan: Pastikan file .env (jika ada) berada di root folder aplikasi sebelum di-build.
